말글 나의 목소리로 채우는 기록텍스트 자동 저장 · Android Chrome용
GOOGLE DRIVE

내 드라이브와 연결하기

처음 한 번 앱 연결 설정이 필요합니다. 연결 후에는 글을 수정하면 2초 뒤 내 드라이브의 TXT 파일에 자동 반영됩니다.

처음 설정하는 방법
  1. Google Cloud Console에서 프로젝트를 만들고 Google Drive API를 사용 설정합니다.
  2. Google Auth Platform에서 동의 화면을 설정하고, 테스트 모드라면 본인의 구글 계정을 테스트 사용자로 추가합니다.
  3. 클라이언트 → 웹 애플리케이션을 생성하고, 승인된 JavaScript 원본에 아래 주소를 추가합니다.
  4. 발급된 클라이언트 ID를 위에 입력합니다. 클라이언트 보안 비밀번호는 입력하지 않습니다.
  5. 설정을 저장하고 Google Drive 연결 버튼을 누릅니다.

이 앱에서 생성한 파일에 대한 권한만 요청합니다. 연결 토큰은 메모리에만 보관되며, 만료되거나 페이지를 다시 열면 재연결이 필요합니다.

음성 인식은 브라우저 제공 서비스를 이용하며 음성이 해당 서비스에 전송될 수 있습니다. 현재 버전은 직접 녹음하면서 변환하는 방식입니다. 기존 음성 파일의 업로드 변환은 지원하지 않습니다.
